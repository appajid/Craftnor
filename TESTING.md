# Desktop smoke testing

On each supported OS/architecture:

1. Install/extract and launch. Confirm the icon, splash and About credits.
2. Enter English and Telugu text, change fonts and confirm readable counters.
3. Try B&W, Color, shape, gold/silver foil impression and material presets.
4. Adjust stamp pressure/grain and background surface scale/strength.
5. Zoom at the cursor, pan, fit the canvas and exercise Undo/Redo.
6. Save a named `.cfnr`, reopen it and compare text, fonts, effects, canvas,
   layers, paper/leather and image settings.
7. Cancel an overwrite and cancel quitting with unsaved changes; confirm work
   remains. Test saving before quit and recovery after an interrupted session.
8. Export SVG, PNG and JPG. Check canvas/background dimensions, counters and
   embedded material appearance in an independent viewer.
9. Check `.cfnr` file association and document icon after installing.

Report OS/version, CPU architecture, Craftnor version, reproduction steps and a
minimal project containing only material you have permission to share.
